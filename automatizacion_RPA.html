¿Qué encontrarás aquí?

Esta sección reúne soluciones orientadas a automatizar procesos repetitivos que requieren interacción constante con aplicaciones, archivos y sistemas.

El objetivo es identificar tareas manuales, definir un flujo automatizado y reducir la intervención necesaria para completar el proceso.

Preparación de transportes en WMS

Automatización de un proceso operativo repetitivo mediante Power Automate Desktop.

Proceso manual

Durante la jornada se deben crear repetidamente transportes en un WMS web e ingresar los datos correspondientes para luego asociar las órdenes que serán transportadas.

El proceso se repite hasta completar las órdenes del día, seguido posteriormente por la impresión de los transportes.

Al ejecutar el flujo, Power Automate Desktop inicia el script encargado de preparar las órdenes y utiliza la información obtenida para continuar automáticamente con la operación en el WMS.

  • Crear un nuevo transporte.
  • Ingresar tipo de transporte.
  • Ingresar Orden Externa 2.
  • Ingresar código de transportista.
  • Utilizar RUT por defecto cuando corresponde.
  • Ingresar código de cliente.
  • Guardar y obtener el ID generado.
  • Asociar las órdenes correspondientes.
  • Repetir el proceso hasta completar las órdenes.

Auto impresión de transportes WMS

Automatización de la impresión de transportes generados durante la jornada mediante Power Automate Desktop.

Proceso manual

Al finalizar la operación, se debe descargar desde el WMS un archivo Excel que contiene los transportes generados y sus órdenes asociadas.

Cada transporte posee un ID único y puede contener una o múltiples órdenes. El proceso de impresión requiere navegar manualmente por el WMS y esperar la carga de cada documento antes de imprimirlo.

Automatización

Power Automate Desktop utiliza el archivo descargado desde el WMS y ejecuta un script para obtener los identificadores únicos de los transportes.

Los IDs son cargados como variables y posteriormente procesados mediante un ciclo For hasta completar todos los registros.

  • Descargar el Excel desde el WMS.
  • Obtener los valores únicos de Num_ID.
  • Cargar los IDs como variables.
  • Ingresar el ID en el WMS.
  • Seleccionar el transporte correspondiente.
  • Ejecutar la opción de finalizar.
  • Esperar la carga de la siguiente página.
  • Localizar el botón de impresión del documento PDF.
  • Seleccionar 2 copias.
  • Imprimir el documento.
  • Volver al proceso y continuar con el siguiente ID.
Control de tiempos de carga

El WMS puede presentar tiempos de respuesta variables durante la navegación. El flujo considera estas esperas antes de continuar con la siguiente etapa, evitando que la automatización avance antes de que el documento esté disponible.

Aprovechamiento del tiempo

El RPA trabaja durante los tiempos de espera generados por el WMS.
