Automatización de procesos con Excel + VBA

Automatización de tareas repetitivas mediante macros de Excel para transformar y estructurar información recibida desde clientes.

Problema

Las solicitudes recibidas desde distintos clientes podían presentar estructuras de archivo diferentes. Para procesarlas era necesario utilizar una plantilla anterior, eliminar los datos existentes, trasladar manualmente la información, completar datos internos y mantener el formato requerido.

Este proceso implicaba múltiples tareas repetitivas y revisiones antes de obtener el archivo final.

Proceso original
  • Abrir una plantilla utilizada anteriormente.
  • Eliminar los datos del proceso anterior, conservando la estructura y formato de la primera fila.
  • Revisar el archivo recibido del cliente.
  • Copiar la información en las columnas correspondientes.
  • Completar información interna requerida.
  • Replicar el formato sobre los nuevos registros.
  • Eliminar la fila utilizada como ejemplo.
  • Revisar cantidades y registros antes de continuar con el proceso.

Selección automática de macro

Se incorporó una lógica para identificar automáticamente la estructura del archivo enviado por el cliente y ejecutar el procedimiento correspondiente.

De esta forma, distintos formatos de solicitud pueden ser procesados desde un único punto de ejecución, manteniendo una misma estructura de salida.

Automatización
  • Identificación de la estructura del archivo recibido.
  • Selección automática de la macro correspondiente.
  • Creación de un nuevo archivo con la estructura y formato definidos.
  • Traspaso de información entre estructuras diferentes.
  • Incorporación de datos internos.
  • Aplicación del formato a los nuevos registros.
  • Generación del archivo final en formato xml.
Validación

La generación del archivo final se mantenía precedida por una revisión de los datos procesados, permitiendo comprobar cantidades de registros, cajas solicitadas y otros valores relevantes antes de continuar con el proceso.

La validación permitió mantener un control sobre el resultado de la automatización y detectar posibles diferencias antes de utilizar el archivo generado.

Reduce el trabajo manual de copiar, ordenar, completar y formatear información.

Estructura estandarizada

Automatización de despacho: MVP de Excel App con UserForm dinámico

Solución desarrollada en Excel y VBA para agilizar la validación y generación de manifiestos de entrega durante el proceso de despacho.

Problema

El proceso de despacho requería validar manualmente los documentos asociados a cada entrega y registrar la información de los pallets procesados.

La validación uno a uno aumentaba el tiempo de procesamiento y el esfuerzo físico y visual, especialmente al trabajar con múltiples envíos.

Solución

Se desarrolló un MVP utilizando Excel y VBA, incorporando un UserForm dinámico para registrar y validar los envíos mediante lectura de códigos de barras.

La información utilizada por la aplicación se consolida mediante Power Query a partir de datos almacenados en SharePoint.

Automatización de procesos SAP con Excel + VBA

Solución desarrollada en Excel y VBA para automatizar tareas repetitivas del proceso de facturación y despacho.

Problema

El proceso requería confirmar el ticket en SAP, contabilizar la entrega, verificar el resultado e imprimir el documento tributario correspondiente.

Estas tareas se realizaban de forma repetitiva mientras el operario continuaba con el proceso físico de picking, aumentando la carga operativa y la posibilidad de errores.

Solución

Se desarrolló una macro en Excel VBA que utiliza los códigos escaneados desde la hoja de picking para ejecutar automáticamente las distintas etapas del proceso en SAP GUI.

La solución evolucionó mediante distintas versiones, incorporando controles de errores, mensajes de SAP e impresión automática del documento.

Evolución

La solución fue evolucionando mediante cuatro versiones, incorporando mejoras progresivas de control y usabilidad.

  • v1.0: automatización básica del proceso.
  • v2.0: mejora de interfaz y control de lectura.
  • v3.0: visualización de mensajes de éxito o error desde SAP.
  • v4.0: búsqueda web e impresión directa del documento.
Solución al problema

Antes de la automatización, preparar a un trabajador para ejecutar correctamente el proceso completo requería conocer las etapas de validación, preparación y facturación en SAP, además del uso de una plataforma web para buscar e imprimir el documento correspondiente.

Este proceso de aprendizaje podía tomar entre una y dos semanas, dependiendo de la experiencia del trabajador.

Con la macro, el proceso se simplificó a identificar los códigos que deben ser pistoleados y presionar un botón para ejecutar las etapas automatizadas. De esta forma, parte importante de la complejidad del proceso queda concentrada en la herramienta y no en el usuario.
